# Shawerma El Shami (شاورما الشامي)

Official website for **Shawerma El Shami** — Authentic Syrian Shawarma restaurant in Temple Terrace, FL.

## Features
- **Authentic Menu Catalog**: Full menu with halal chicken & beef shawarma, platters, appetizers, and house sauces.
- **Shami AI Menu Sommelier**: Client-side conversational AI assistant that offers dish recommendations with strict food-only guardrails.
- **Dark / Light Mode**: One-click theme switcher with persistent local storage.
- **Fast-Start HD Hero Video**: Web-optimized 1080p background video.
- **Fully Responsive**: Mobile-first design with sticky call-to-order bar.
